## Как запустить локально
1. Открыть папку проекта в Visual Studio Code.
2. Для просмотра фронтенда запустить любой локальный сервер (например, расширение Live Server) или команду `python -m http.server 5500` в корневой папке.
3. Для запуска бэкенда (сервера) перейти в папку `backend` и выполнить:
   - `pip install -r requirements.txt`
   - `uvicorn main:app --reload`

## Что сделано
- **ПР №1:** 5 страниц (Главная, Каталог, Товар, Корзина, Контакты). Адаптивная вёрстка (Flexbox/Grid), семантическая разметка, свой дизайн.
- **ПР №2:** Работа с API курсов валют (fetch), фильтрация каталога, валидация формы обратной связи, корзина.
- **ПР №3:** Написан сервер на Python (FastAPI). Создана база данных SQLite (3 таблицы: товары, пользователи, корзина). Настроены обработчики (список товаров, регистрация, вход). Пароли хешируются (bcrypt).
- **ПР №4:** Приложение упаковано в Docker (Dockerfile). Сервер развернут на Render.com с HTTPS. Фронтенд размещен на GitHub Pages. Настроено взаимодействие между ними через API.
