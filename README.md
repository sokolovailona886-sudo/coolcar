Вариант задания
№13. Магазин автомобильных аксессуаров. Подбор по марке и модели автомобиля.
Группа А — Каталог и подбор.

Как запустить
1. Открыть папку `coolcar` в Visual Studio Code.
2. Открыть файл `index.html` в браузере (двойной клик по файлу в проводнике 
   или правой кнопкой → Open with Live Server).
3. Перемещаться между страницами через меню в шапке.

Никакие библиотеки/сервер не требуются — это статический сайт на HTML + CSS.
